# English Town 3D

英語クイズに答えて資源を集め、3Dの街を育てるブラウザゲームです。

## 遊び方
1. 英語クイズの正しい日本語訳を選びます。
2. 正解すると木材とコインを1つずつ獲得します。
3. 建設メニューから公園・家・カフェ・ビルを選び、3Dマップの空き地をタップします。
4. ドラッグで視点を回転、スクロールやピンチで拡大・縮小できます。
5. セーブデータはブラウザの localStorage に保存されます。

## 起動方法
GitHub Pages を有効にすると、公開URLから遊べます。Three.js はCDNから読み込むため、プレイ時はインターネット接続が必要です。

## 技術
- HTML / CSS / JavaScript
- Three.js r128
- Web Speech API（英語の発音）
- localStorage（ローカルセーブ）
